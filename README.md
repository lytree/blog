# blog

杨 ◦ 柳 · 日常随笔站点 —— 基于 **Hexo 8 + Butterfly 5**，记录平淡生活里的微光。

源码：[github.com/lytree/blog](https://github.com/lytree/blog) · 站点：[blog.prideyang.top](https://blog.prideyang.top/)

## 写作约定

- 文章位于 `source/_posts/`，按 `年/月/` 分目录存放，命名规则为 `/:year/:month/:title.md`。

- 开启 `post_asset_folder`，每篇文章可拥有同名资源目录，图片随文章一起管理。

- 站点信息、永久链接、部署方式在 `_config.yml` 中配置；主题外观、导航、代码块等在 `_config.butterfly.yml` 中配置。

- 独立页面放在 `source/` 下，例如 `source/about/index.md`、`source/music/index.md`。

## 功能特性

- 首页、标签、分类、归档、关于五个导航入口

- KaTeX 数学公式

- 代码块复制、折叠、全屏与语言标签

- 暗色模式、Pjax 局部刷新

- 文章版权、目录、分享等主题能力
